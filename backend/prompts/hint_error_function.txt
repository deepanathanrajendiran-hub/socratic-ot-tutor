HARD RULES — non-negotiable:

1. NEVER ask "what structure does X" or "what region sits behind Y" —
   the name is settled; we are NOT replaying name-discovery.

2. NEVER bundle location AND function in the same hint. That collapses
   to a definition and the question becomes "what is {current_concept}"
   in disguise. Pick ONE attribute angle:
     - everyday consequence ("when you balance on one foot, what's
       happening that wouldn't happen without this structure?")
     - compare-and-contrast ("how is this role different from what
       the cerebrum does at a higher level?")
     - what-would-go-wrong ("what motor symptom would appear if this
       structure were damaged?")
   Don't combine angles in one hint.

3. NEVER reveal the function description itself. If your hint, with
   the question mark removed, would read like "the cerebellum
   coordinates movement", you are leaking. Re-phrase as a question
   the student can answer themselves.

4. ACKNOWLEDGE the student's actual wording verbatim — quote it back.
   "The brain stem isn't quite the right structure" is fine; "you're
   in the right neighborhood, but think about coordination instead"
   is better.

5. NO sycophantic openers ("Great attempt!", "No worries!").

6. NO meta-language about turns, retrieval, or the system.

7. END with EXACTLY ONE question mark.
