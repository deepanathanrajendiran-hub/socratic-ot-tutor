DECISION PROCEDURE — follow these steps in order
═══════════════════════════════════════════════════════════════

STEP 0 — Is the student ASKING TO LEARN about something (not
asserting knowledge)?
  Recognize question / request intent regardless of whether the
  concept name appears. Common patterns:
    "tell me about X" / "tell me X"
    "what is X?" / "what's X?" / "what are X?"
    "explain X" / "can you explain X?"
    "describe X" / "describe how X works"
    "how does X work?" / "how do X work?"
    "why does X happen?" / "why is X important?"
    "can you teach me about X?"
    "I want to learn about X"
    "what's the role of X?"
    "what does X do?"
  → questioning

  CRITICAL: a message like "Tell me about the {current_concept}" is
  ALWAYS questioning — the student is requesting an opening
  explanation. Naming the concept inside a learn-request does NOT
  make it a correct answer; the student hasn't been asked anything
  yet. Only direct assertions of an answer ("it's X", "the answer is
  X", "I think X", or a bare "X" in response to a prior question)
  count toward STEP 3.

STEP 1 — Is the student saying they don't know / asking for help WITHOUT
naming any specific anatomical structure?
  → idk

STEP 2 — Did the student NAME or DESCRIBE a specific anatomical
structure as their answer (e.g. "the median nerve", "the spinal cord",
"the brachial plexus")?
  - NO and the message is unrelated to anatomy / OT → irrelevant
  - NO and the message is a clarifying question about a concept → questioning
  - YES → continue to STEP 3

STEP 3 — Does the named or described entity match {current_concept},
OR is it a textbook synonym of {current_concept}?
  Accept all of the following as "correct":
    - exact name, plural, adjectival
    - universally-recognized synonym
    - obvious misspelling / phonetic variant where the intended
      word is unmistakably {current_concept}.
      Examples: "synapis" / "synaps" / "sinapse" → "synapse";
                "cerebelum" / "cerebellem"        → "cerebellum";
                "ulner" / "ulna nerve"            → "ulnar nerve";
                "brachail plexus"                 → "brachial plexus".
      A misspelling counts only when it leaves no doubt about the
      intended structure. Do NOT promote a guess that names a
      DIFFERENT structure ("axon" vs "synapse") just because the
      letters partly overlap.
  - YES (any of the above) → correct
  - NO  (different entity — even if it's the same kind of thing as
    {current_concept}) → incorrect

CRITICAL: When the student names a specific entity that does NOT match
{current_concept}, the verdict is INCORRECT — even if the named entity
is in the SAME CATEGORY as the concept (a different nerve when concept
is a nerve; a different law when concept is a physical law; a different
muscle when concept is a muscle). Do NOT auto-pass "shape-of-an-answer"
attempts. The named entity itself must match {current_concept} for the
verdict to be "correct".
